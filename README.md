# ربات کتابخانه تلگرام

نسخهٔ آمادهٔ انتشار ربات کتابخانه با اصلاح پاسخ ادمین، جایگزینی امن دیتابیس از داخل تلگرام و نصب سرویس systemd.

## چه چیزهایی اصلاح شده؟

- پاسخ ادمین به پیام‌های کاربران با نگاشت پایدارِ شناسهٔ پیام ارسالی به ادمین و شناسهٔ کاربر انجام می‌شود؛ دیگر برای پیام‌های جدید به استخراج شکنندهٔ شناسه از HTML وابسته نیست.
- handler پاسخ ادمین در گروه اولویت‌دار است؛ بنابراین مکالمه‌های مدیریتی دیگر پیام Reply را قبل از ارسال پاسخ نمی‌بلعند.
- پاسخ متنی و فایل/رسانه‌ای ادمین پشتیبانی می‌شود. اعلان‌های قدیمی نیز تا حد ممکن با روش سازگاری قبلی قابل پاسخ هستند.
- ادمین می‌تواند در گفت‌وگوی خصوصی ربات یک فایل با پسوند `.db`، `.sqlite` یا `.sqlite3` بفرستد. فایل باید دیتابیس SQLite سالم و دارای جدول‌های لازم باشد. پیش از جایگزینی، از دیتابیس فعلی پشتیبان ساخته می‌شود.
- توکن، شناسهٔ کانال و شناسه‌های ادمین از متغیر محیطی خوانده می‌شوند و داخل کد نیستند.

## نصب تک‌دستوری روی Ubuntu/Debian

ابتدا فایل‌های این پوشه را در ریشهٔ مخزن عمومی [`arefhere51/ravanbookbot`](https://github.com/arefhere51/ravanbookbot) روی شاخهٔ `main` قرار دهید. سپس دستور زیر را در سرور اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/arefhere51/ravanbookbot/main/install.sh | sudo bash
```

نصب‌کننده آدرس مخزن را از قبل دارد؛ توکن ربات را به‌شکل مخفی، شناسهٔ کانال و شناسه‌های عددی ادمین را می‌پرسد؛ سپس کد را از GitHub می‌گیرد، وابستگی‌ها را نصب و سرویس `systemd` را فعال می‌کند. در صورت نیاز می‌توانید آدرس پیش‌فرض را با متغیر `BOT_REPO_URL` تغییر دهید:

```bash
curl -fsSL https://raw.githubusercontent.com/arefhere51/ravanbookbot/main/install.sh | sudo env BOT_REPO_URL=https://github.com/arefhere51/ravanbookbot.git bash
```

مخزن باید `bot.py` و `requirements.txt` را در ریشه داشته باشد. نصب‌کننده فقط برای Ubuntu/Debian طراحی شده و به دسترسی root و ترمینال تعاملی نیاز دارد.

## استفاده از جایگزینی دیتابیس

1. با یکی از اکانت‌های ادمین در گفت‌وگوی خصوصی ربات، فایل دیتابیس را به‌صورت **Document** ارسال کنید.
2. نام فایل باید به `.db`، `.sqlite` یا `.sqlite3` ختم شود و حجم آن حداکثر ۲۰ مگابایت باشد.
3. ربات سلامت SQLite و وجود جدول‌های لازم را بررسی می‌کند؛ اگر موفق باشد فایل را جایگزین می‌کند و نام پشتیبان قبلی را اعلام می‌کند.
4. پشتیبان قبلی با نامی شبیه `before_restore_YYYYMMDD_HHMMSS.db` کنار دیتابیس نگه داشته می‌شود.

این عملیات فقط از ادمین مجاز و در چت خصوصی پذیرفته می‌شود. فایل نامعتبر جایگزین نمی‌شود.

## مدیریت سرویس

```bash
sudo systemctl status pdf-library-bot
sudo journalctl -u pdf-library-bot -f
sudo systemctl restart pdf-library-bot
```

تنظیمات در `/opt/pdf-library-bot/.env` ذخیره می‌شوند و مجوز فایل محدود است. فایل را در GitHub یا پیام عمومی قرار ندهید.

## هشدار امنیتی مهم

توکن نسخهٔ اولیه در سورس کد قرار داشت و افشا شده است. پیش از اجرای نسخهٔ جدید، توکن قبلی را در **BotFather باطل کنید و توکن تازه بگیرید**؛ سپس توکن تازه را فقط در نصب‌کننده وارد کنید. توکن افشاشده را دوباره استفاده نکنید.

## پنل مدیریت وب (Admin Panel)

یک پنل مدیریتی وب روی **پورت ۱۳۴۲۳** اضافه شده که از طریق مرورگر قابل دسترسی است و تقریباً همه کارهای ادمین را پوشش می‌دهد:

### امکانات پنل
- **داشبورد آمار**: تعداد آیتم‌ها، کاربران، دانلودها، جستجوها، آمار ۲۴ساعته، برترین آیتم‌ها، آخرین فعالیت‌ها
- **مدیریت آیتم‌ها**: جستجو، ویرایش عنوان/توضیحات/دسته/تگ، بایگانی، حذف، مشاهده فایل‌ها و لاگ دانلود
- **دسته‌بندی‌ها**: افزودن، ویرایش، حذف (با پشتیبانی والد)
- **کاربران و دعوت**: لیست کاربران، معاف کردن / لغو معافیت، تنظیم حد نصاب دعوت، صفر کردن دعوت‌ها
- **عضویت اجباری**: فعال/غیرفعال، افزودن و حذف کانال
- **تنظیمات**: پیام خوش‌آمد، منوی اصلی، پاورقی سراسری، دکمه درخواست محتوا، دکمه‌های داینامیک
- **لاگ دانلود و جستجو**: مشاهده تاریخچه با صفحه‌بندی
- **سیستم**: حجم دیتابیس، لیست جداول، دانلود فایل پشتیبان `.db`

### اجرای پنل

```bash
# از ریشه پروژه
export ADMIN_PANEL_PASSWORD='رمز_قوی_خودتان'   # الزامی در محیط واقعی
export ADMIN_PANEL_PORT=13423                   # پیش‌فرض
# اختیاری: مسیر دیتابیس اگر غیر از پیش‌فرض است
# export DB_PATH=/opt/pdf-library-bot/pdf_library.db

pip install Flask Werkzeug
# یا از requirements.txt
pip install -r requirements.txt

python3 web_admin/app.py
# یا
bash web_admin/run_admin.sh
```

سپس در مرورگر باز کنید: `http://SERVER_IP:13423`

### متغیرهای محیطی پنل
| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `ADMIN_PANEL_PASSWORD` | `admin123` | رمز ورود پنل (حتماً عوض کنید) |
| `ADMIN_PANEL_PORT` | `13423` | پورت سرویس |
| `ADMIN_PANEL_HOST` | `0.0.0.0` | آدرس bind |
| `ADMIN_PANEL_SECRET` | تصادفی | کلید session Flask |
| `DB_PATH` | `./pdf_library.db` | مسیر فایل SQLite ربات |

> پنل و ربات از **همان فایل دیتابیس** استفاده می‌کنند. برای محیط production بهتر است پنل را پشت reverse-proxy (مثلاً nginx) با HTTPS قرار دهید و رمز قوی بگذارید.

### سرویس systemd نمونه برای پنل

```ini
[Unit]
Description=PDF Library Bot Admin Panel
After=network-online.target

[Service]
Type=simple
User=pdfbot
WorkingDirectory=/opt/pdf-library-bot
EnvironmentFile=/opt/pdf-library-bot/.env
Environment=ADMIN_PANEL_PORT=13423
Environment=ADMIN_PANEL_PASSWORD=CHANGE_ME
ExecStart=/opt/pdf-library-bot/venv/bin/python /opt/pdf-library-bot/web_admin/app.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```
